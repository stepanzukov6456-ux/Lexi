# Lexi 0.2

Мобильное PWA без сборки и зависимостей. Интерфейс на русском, карточки английский—русский. 

## Публикация
1. Создай публичный репозиторий `lexi` на GitHub. Загрузи файлы из этого архива в корень ветки main (не вложенную папку).
2. Settings → Pages → Deploy from a branch → main → / (root) → Save. Дождись публикации.
3. Открой выданный HTTPS-адрес в Safari на iPhone. Поделиться → На экран «Домой». Открой приложение при наличии интернета для загрузки офлайн-кэша.

## Синхронизация
1. Создай отдельный **приватный** репозиторий `lexi-data`, отметь Add README, чтобы существовала ветка.
2. GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Выбери только lexi-data, Contents: Read and write. Задай срок действия.
3. В Lexi → Настройки введи `имя/lexi-data` и токен. Повтори на других устройствах. Не публикуй токен и не присылай его в чат.
4. Изменения отправляются после сохранения, при открытии, восстановлении сети и каждую минуту при открытом приложении. Обновление одного файла использует SHA GitHub. Разные карточки объединяются по ID; при одновременной правке одной карточки побеждает более свежая по времени устройства. Удаления сохраняются как метки. Не гарантируется синхронизация при закрытом приложении. Токен хранится в IndexedDB без шифрования; не используй на чужих устройствах. История GitHub сохраняет прежние версии, включая удалённые карточки. Для крупной базы понадобится другой способ хранения; текущий API ограничен размером файла.

## Форматы
CSV: term,definition,example,exampleTranslation,folder,tags. UTF-8, разделитель запятая, первая строка заголовок. JSON сохраняет также расписание и ID. Импорт JSON объединяет данные, CSV создаёт новые карточки. Массовый ввод: слово | перевод | пример | перевод примера. 

## Разработка
`python -m http.server 8000` для локального тестирования на localhost; `npm test` проверяет слияние, CSV и расписание. model.js — модель и алгоритм повторения; storage.js — IndexedDB; sync.js — адаптер GitHub; app.js — интерфейс. Для следующих версий можно выделить адаптер ИИ и голосового ввода. При обновлении файлов поменяй CACHE в sw.js. При очистке данных браузера локальная база может исчезнуть: регулярно экспортируй JSON. 

## Ограничения
Упрощённое интервальное повторение (10 минут / 1 день / растущий интервал), не FSRS. Нет ИИ, голоса, нативной Windows-версии. Проверены синтаксис JS и базовые функции модели; реальные Safari, GitHub и офлайн-режим не проверены в этой среде. Импорт и синхронизация требуют проверки на реальных устройствах перед использованием для важных данных.

## Импорт из ChatGPT
Скопируй chatgpt-prompt.txt в отдельный чат ChatGPT. Отправляй слова, фразы или предложения, копируй JSON и вставляй в «Импорт из ChatGPT» на главном экране. Выбери папку, распознай карточки, проверь предварительный просмотр и сохрани. Поддерживаются одиночный объект, массив и объект cards, а также JSON в блоке кода. Ошибочный JSON не сохраняется. Повторный импорт создаёт новые карточки. Импорт работает офлайн; получение ответа ChatGPT требует интернета. API не используется.
